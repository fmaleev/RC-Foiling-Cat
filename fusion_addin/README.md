# Sail Trim add-in (copy)

The Fusion add-in that trims the rig with three sliders (jib sheet, main traveler, mainsheet tension). Fusion loads it from
`~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/SailTrim/`; this folder is a copy kept with the
project because `rig_model.py` also feeds the analysis and the build manuals (rigging lengths, sail patterns).
To install, copy the folder there and enable it in Fusion (Utilities > Add-Ins).
